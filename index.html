🛡️ Install SecureX

Follow these steps to add SecureX to your Chrome browser.

  1. Download the ZIP: Click the button below to open our GitHub repository.
  2. Download the file: Click on the file named SecureX.rar.
  3. Extract the files: Right-click the downloaded file and select "Extract All" (Windows) or double-click it (Mac).
  4. Open Chrome Extensions: Type chrome://extensions/ in a new tab and press Enter.
  5. Enable Developer Mode: Toggle the switch in the top-right corner to ON.
  6. Load the Extension: Click "Load unpacked" and select the extracted folder.
  7. Pin to Toolbar: Click the puzzle icon 🧩 in Chrome and pin SecureX.
